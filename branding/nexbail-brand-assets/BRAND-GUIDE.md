# Nexbail — guide de marque

Ces fichiers constituent les masters raster officiels approuvés de Nexbail. Ils proviennent de la référence officielle et ne doivent pas être redessinés, retracés ni régénérés.

## Palette officielle

- Bleu principal : `#2563EB`
- Navy : `#0F172A`
- Fond clair : `#EFF6FF`
- Gris : `#64748B`
- Succès : `#16A34A`
- Attention : `#F59E0B`
- Erreur : `#EF4444`

## Typographie

L’interface utilise **Geist Sans**. **Geist Mono** est réservé aux valeurs techniques ou tabulaires qui nécessitent une police monospace. Le wordmark Nexbail est un élément graphique raster : il ne doit pas être recomposé avec une police.

## Tagline

**La gestion locative, simplement.**

Respecter exactement la casse, la ponctuation et l’accentuation.

## Usage sur fond clair

Utiliser `logo/logo-nexbail-horizontal-light.png` ou sa version transparente. Le wordmark navy est prévu pour les surfaces claires. Utiliser le monogramme seul lorsque l’espace ne permet pas de conserver le logo horizontal lisible.

Dans les emplacements compacts, utiliser `logo/logo-nexbail-horizontal-compact-light.png`. Cette variante conserve exactement le N et le wordmark du master et retire uniquement la tagline devenue illisible à petite taille.

## Usage sur fond sombre

Utiliser `logo/logo-nexbail-horizontal-dark.png` ou sa version transparente. Le wordmark blanc est prévu pour les surfaces navy ou sombres. Ne pas ajouter de carré blanc derrière le logo.

Dans les emplacements compacts, utiliser `logo/logo-nexbail-horizontal-compact-dark.png`. La sidebar réduite, les favicons et les icônes PWA utilisent le monogramme seul.

## Règles minimales

- Conserver les proportions et laisser une zone de respiration au moins égale à la largeur d’un segment du monogramme.
- Ne modifier ni la géométrie, ni les dégradés, ni les couleurs du symbole.
- Ne pas étirer, incliner, recadrer ou recomposer le wordmark.
- Utiliser les favicons fournis à leur taille exacte.
- Utiliser les fichiers PWA 192 et 512 avec `purpose: any`; ils ne sont pas certifiés comme icônes maskables.
- Utiliser le logo email sur fond clair et fournir un texte alternatif « Nexbail ».
- Le master source est raster. L’icône 1024 px est un agrandissement approuvé, pas un fichier vectoriel natif.
