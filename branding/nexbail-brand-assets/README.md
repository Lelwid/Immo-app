# Nexbail — assets officiels approuvés

Source officielle : ../Imagen de ChatGPT 28 sept 2026, 09_23_28 p.m..png.

Le N et le wordmark ont été extraits du même fichier raster, sans tracé manuel ni génération d’une nouvelle géométrie. Nettoyage du halo par remappage de l’alpha (80 → transparent, 240 → opaque) ; contours anticrénelés conservés mais ce n’est pas une reproduction pixel pour pixel du halo. Le logo source avec halo est fourni séparément. Les dégradés bleus du symbole source sont conservés. Les fonds d’icônes et couleurs de texte utilisent la palette demandée.

Tagline : La gestion locative, simplement. — Arial pour cette ligne ajoutée ; le wordmark provient de l’image.

Le symbole source mesure environ 356 × 458 px ; les exports 512/1024 sont interpolés. Aucun SVG vectoriel natif n’est revendiqué. Les icônes PWA sont prévues pour purpose=any ; ne pas les déclarer maskable sans contrôle spécifique.

Ouvrir index.html ou preview/nexbail-assets-review.png pour consulter le pack. Dimensions et empreintes : manifest.json.

Ces fichiers ont été approuvés pour l’intégration Nexbail. Ne pas les régénérer ni redessiner le symbole.
